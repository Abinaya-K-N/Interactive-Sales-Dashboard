# 📊 Interactive Sales Dashboard

An interactive and statistical sales dashboard built using **Python, Seaborn, Matplotlib, and Plotly**. This project visualizes sales trends, regional performance, and product insights using both static and interactive charts.

---

## 🚀 Features

* Statistical visualizations using Seaborn
* Interactive dashboard using Plotly
* Correlation heatmaps and distribution plots
* Multi-chart dashboard layout
* Clean and organized project structure
* Error handling and reusable code

---

## 📁 Project Structure

```
Interactive_Sales_Dashboard/
│
├── dashboard.ipynb          # Main notebook dashboard
├── dashboard.py             # Python script version
├── sales_data.csv           # Dataset used
├── requirements.txt         # Required libraries
├── dashboard_demo.mp4      # Dashboard demo recording
│
├── visualizations/          # Generated charts
│   ├── boxplot.png
│   ├── violinplot.png
│   ├── heatmap.png
│   ├── subplot_dashboard.png
│   └── interactive_dashboard.html
```

---

## 📊 Visualizations Included

* Box Plot – Sales distribution by region
* Violin Plot – Sales density visualization
* Heatmap – Correlation between variables
* Bar Chart – Regional sales comparison
* Histogram – Sales frequency distribution
* Line Chart – Sales trends over time
* Interactive Dashboard – Fully interactive Plotly chart

---

## ⚙️ Installation

Install required libraries:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Dashboard

Run using Python script:

```bash
python dashboard.py
```

OR open and run:

```
dashboard.ipynb
```

---

## 🌐 Interactive Dashboard

Download and open:

```
visualizations/interactive_dashboard.html
```

in your browser to view the interactive dashboard.
